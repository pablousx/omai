03 / YOUR CONFIGURATION, YOUR CALL

Your remote.
Your control.

omai synchronizes through ordinary Git. There’s no omai cloud account, hosted configuration database, or usage analytics in the plugin.

Authentication stays with your Git tools and AI providers. Use a trusted remote: configuration can include executable hooks and commands, and content checks cannot recognize every secret.

04 / ONE SMALL ADDITION

Make room for omai.

Add the plugin to Omarchy, then do the rest in its window. Your AI tools keep working as usual.

Requires Omarchy 4.0.3 or later on Linux x86-64, Git, curl, Python 3.11+, and a systemd user session. Bring a Git remote to sync across computers.

Installation & documentation ↗
Terminal Install the plugin
$omarchy plugin add https://github.com/pablousx/omai.git --enable --yes

  1. Open the ✦ icon. Choose Set up omai.
  2. Connect a remote or stay local. Review the import options.
  3. Start syncing. Setup installs the companion executable when needed.

Setup uses the matching published release. For an unpublished local checkout, the panel offers a source-build retry.

05 / GOOD TO KNOW

A few practical details.

Does omai require a cloud account?

No omai account is needed. Local sync works without a remote. To sync across computers, bring an existing Git repository and its usual authentication.

Will it mix my providers’ configurations?

Newly discovered instructions, skills, rules, and MCP declarations stay scoped to their provider. Explicitly shared source entries are also supported when you want them.

What happens while I’m offline?

Local reconciliation continues and your changes remain on your computer. When automatic sync is running, omai retries the remote connection.

What if two computers change the same thing?

omai keeps both versions and asks you to choose. It doesn’t silently pick the newest edit or force-push over another computer’s work.

What stays out of the synced source?

Credentials, account databases, sessions, histories, caches, and project-level configuration stay local. Resource files must be text. Linked user skills are read as snapshots; omai does not overwrite their package-managed targets.

Can I pause, undo, or stop using it?

Yes. Pause from the panel, review recovery history in Advanced, or confirm Undo last apply. Clearing settings stops sync and returns to setup while keeping your configuration files. Removing only the bar plugin does not stop its companion service; see the operations guide.
