# Code of conduct

Everyone participating in this project should be able to collaborate respectfully, regardless of background, identity, experience, or ability.

Be considerate, welcome questions, accept constructive feedback, and discuss ideas without personal attacks. Harassment, threats, discriminatory language, sexual attention, impersonation, and sharing another person's private information are unacceptable.

These expectations apply to project issues, pull requests, discussions, and other spaces where people represent the project.

Maintainers may edit or remove inappropriate contributions, warn participants, or restrict participation. They should explain decisions when doing so does not expose private information and handle reports discreetly.

Use GitHub's **Report content** or **Block or report user** controls for abuse. Do not post sensitive reports publicly.
